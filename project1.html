SOLARWISE: PLATFORM KEPUTUSAN ENERGI SURYA ATAP

Platform decision-support berbasis web modern yang menghitung estimasi biaya instalasi, kelayakan teknis, proyeksi penghematan listrik, dan potensi Return on Investment (ROI) PLTS atap secara instan berdasarkan koordinat lokasi presisi dan profil konsumsi tagihan rumah tangga.

LATAR BELAKANG & TUJUAN PLATFORM

Transisi energi di Indonesia menghadapi tantangan adopsi PLTS atap residensial yang masih rendah akibat hambatan regulasi, ketidakpastian finansial, dan ketidakjelasan waktu pengembalian investasi (payback period). SolarWise hadir memberikan transparansi data berbasis lokasi agar calon pengguna dapat mengambil keputusan investasi energi bersih secara objektif dan terukur.

ARSITEKTUR FULL-STACK & API

  • Frontend Engine: Next.js 15 (Turbopack), TypeScript, Tailwind CSS dengan UI/UX modern dan responsif
  • Backend Service: Golang high-concurrency calculation engine dengan endpoint RESTful API (/v1/simulation)
  • Geocoding Precision: Integrasi Google Maps Platform API untuk konversi alamat ke koordinat presisi
  • Real-time Solar Data: Integrasi NASA POWER API untuk penarikan data radiasi matahari dan meteorologi

ENVIRONMENT ANALYSIS (FASE 1)

Pada alur awal simulasi, pengguna memasukkan nama lokasi/alamat dan rata-rata tagihan listrik bulanan. Sistem melakukan geocoding koordinat via Google Maps API, kemudian melakukan fetching data radiasi harian (kWh/m²/hari) ke NASA POWER API. Setelah validasi radiasi (>0), sistem menghitung konsumsi dasar dan meneruskan parameter ke mesin optimasi.
